What is an Algorithm?

A step-by-step procedure or set of rules used for solving a specific problem or performing a computation.

Why do we write Algorithms before coding?
  • Documents solution ideas clearly before writing source code.
  • Helps programmers detect logical errors early in development.
  • Allows comparing efficiency between multiple solution strategies.

2. Standard Flowchart Symbols

Graphical representation symbols used in algorithm design

Visual Symbol Symbol Name Function & Purpose
Start / End
Oval / Terminal Marks the beginning or termination point of the algorithm flowchart.
Input / Output
Parallelogram Represents input operations (reading variables) or output operations (printing results).
Process
Rectangle Represents arithmetic calculations, assignments, or internal instruction steps.
Decision
Diamond Represents conditional branching (Yes/No or True/False decisions).

4. Solved Lab Tasks

Complete solutions for the course manual assignments

Task 1

Write an algorithm to print the average temperature of T1, T2, T3.

Step 1: Read inputs T1, T2, T3

Step 2: Calculate Average = (T1 + T2 + T3) / 3

Step 3: Print Average

Task 2

Write an algorithm to calculate average temperature and print "cold" if less than 17, and "hot" if >= 17.

Step 1: Read inputs T1, T2, T3

Step 2: Calculate Average = (T1 + T2 + T3) / 3

Step 3: Print Average

Step 4: If Average < 17 THEN print "cold" ELSE print "hot"

Task 3

Write an algorithm to calculate the value of the function F(x, y) = 2x + 3y.

Step 1: Read variables x and y

Step 2: Compute F = (2 * x) + (3 * y)

Step 3: Print F

5. Extra Practice Questions

Interactive practice with toggleable solutions

Question 1: Find Largest of Two Numbers (A and B)

Step 1: Input numbers A and B

Step 2: If A > B then print "A is larger"

Step 3: Else If B > A then print "B is larger"

Step 4: Else print "Both numbers are equal"

Question 2: Rectangle Area & Perimeter Calculation

Step 1: Read Length (L) and Width (W)

Step 2: Compute Area = L * W

Step 3: Compute Perimeter = 2 * (L + W)

Step 4: Output Area and Perimeter

6. What We Learned From This Lab

Summary of key software engineering takeaways

1. Plan First

Never jump straight into writing code. Solving logic on paper saves hours of syntax and logical debugging.

2. Logic Independence

Algorithms provide a language-agnostic roadmap that can be implemented in Java, C++, Python, or C#.

3. Visual Communication

Flowcharts make decision branches and loops instantly readable for instructors, peers, and engineering teams.
